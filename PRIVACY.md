# Privacy

Humanize AI Slop is a skill-only plugin. It runs no external server, requires no account, and does not collect, store, or sell personal data.

The text you submit is processed by the AI agent where you use the skill (Claude Code, ChatGPT, Codex, or another compatible agent). That processing follows the privacy terms of that product, not of this repository.

Visiting the repository on GitHub may generate the usual server and analytics logs under GitHub's own policy.

Questions: open an [issue](https://github.com/Esl1h/humanize-ai-slop/issues).
